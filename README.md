G64 Improved adds one major feature to G64, movement only mode. <br/>
This mode makes is so you have all the abilites of a normal Gmod player, but have Mario's Movement. 
Along with this comes dedicated VRMod Support! Allowing you to experience accurate Mario 64 movement in VR at a good frame rate!

Additions: <br/>
Movement Mode: Play as the normal player controller, but parented to Mario's movements letting you use guns! <br/>
Spawn as Mario: Automatically spawn as Mario on server start (great for gamemodes and whatnot, also not in yet) <br/>
VR Support! <br/>
